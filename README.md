## Speedometer Project:

## Overview:

This project is a simple interactive speedometer built using HTML, CSS, and JavaScript. It allows users to increase and decrease the displayed speed while watching the speedometer needle move and the scale indicators change accordingly.

## Features:

- Interactive speed controls.
- Speed range from 0 to 180 KMPH.
- Speed changes in steps of 10.
- Animated needle movement.
- Dynamic speed display.
- Color-changing speed indicators.
- Smooth needle rotation.

## Technologies Used:

- **HTML5** – Used to create the structure and elements of the speedometer.
- **CSS3** – Used for styling, positioning, colors, and needle animations.
- **JavaScript** – Used to handle speed changes, update the display, and control the needle movement.

## Project Structure:

- index.html – Contains the speedometer structure and buttons.
- style.css – Handles the design, layout, scale, and animations.
- logic.js – Controls the speed functionality and interactive elements.

## How It Works:

1. The speed starts at 0 KMPH.
2. Clicking the Increase Speed button increases the speed by 10.
3. Clicking the Decrease Speed button decreases the speed by 10.
4. JavaScript updates the speed displayed on the screen.
5. The needle rotates according to the selected speed.
6. The scale indicators change color as the speed increases or decreases.

The speed is limited to a minimum of 0 and a maximum of 180 KMPH.

## How to Run:

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open "index.html" in a web browser.
4. Use the Increase Speed and Decrease Speed buttons to operate the speedometer.
